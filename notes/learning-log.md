# Learning Log

## 2026-10-05｜建立多 Agent 学习实验仓库

### 起因
在使用 AI 辅助开发时，逐渐发现持续复制粘贴、人工转述上下文的方式难以扩展。

### 当前核心认识
- 不应该依赖一个万能 Agent 承担所有职责。
- 多 Agent 的价值来自分工、边界、交接和共享状态。
- “群聊”只是可视化表现，真正关键的是任务状态和责任流转。
- 共享项目文件可以成为多个 Agent 的共同事实来源。
- MCP 是给 Agent 接工具的方式之一，不等于多 Agent 本身。
- 服务器是运行环境问题，应在理解协作机制后再考虑。

### 当前目标
先把团队协作机制理解清楚，再开始真正写多 Agent 实验代码。

### 下一步要继续理解
Agent 之间具体如何交接，以及哪些情况应该自动处理、哪些情况必须让人类介入。
