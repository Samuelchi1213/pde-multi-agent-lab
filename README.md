# PDE Multi-Agent Lab

这是一个用于学习、实验并逐步搭建 **多 Agent AI 开发团队** 的仓库。

## 项目目标

目标不是训练成为传统软件工程师，而是逐步掌握一种新的开发方式：

> 人负责目标、边界、关键决策与最终验收；  
> Agent 团队负责分析、设计、开发、测试、交接与状态同步。

最终希望形成一套可以复用到不同项目和陌生领域的 AI 开发团队模板。

## 当前阶段

目前处于 **Phase 0：理解与设计多 Agent 协作机制**。

当前重点不是大量写代码，而是先理解：

- Agent 之间为什么要分工
- 多个 Agent 如何共享同一个项目状态
- Agent 之间在哪里交接
- 什么应该自动推进
- 什么必须由人类确认
- MCP、工具、服务器分别解决什么问题

## 计划中的 Agent 角色

- PM Agent：任务调度、进度与交接
- Product Agent：需求、业务规则、验收标准
- Architect Agent：技术方案、结构与接口
- Developer Agent：代码实现与修复
- QA Agent：测试、缺陷与回归

## 项目文件

- `PROJECT.md`：项目长期目标与边界
- `CURRENT.md`：当前进度与正在思考的问题
- `TASKS.md`：学习与实验任务
- `DECISIONS.md`：重要决定及原因
- `agents/`：各 Agent 的角色说明
- `notes/learning-log.md`：学习日志
- `experiments/`：后续实验代码与样例

## 原则

1. 先理解，再搭建。
2. 先做最小团队，再增加 Agent。
3. 不追求“群聊效果”，优先保证角色、状态、交接与责任清楚。
4. 项目状态以仓库文件为准，不依赖某一次聊天记录。
5. 任何涉及密钥、个人隐私、真实学生数据的内容都不得提交到仓库。
