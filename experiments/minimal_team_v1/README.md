# 最小三智能体闭环 v1

这是 PDE 多智能体团队的第一个可运行原型。

## 目标

先不接真实大模型，只验证最核心的协作机制：

项目协调智能体
→ 开发智能体
→ 测试智能体
→ 测试失败
→ 项目协调智能体退回返工
→ 开发智能体再次处理
→ 测试智能体再次测试
→ 通过
→ 完成

## 为什么第一版不直接接大模型

因为我们要先确认“团队怎么流转”是对的，再加入模型、工具和 MCP。

这能避免把两个问题混在一起：
- 多智能体编排是否正确
- 模型本身是否输出正确

## 运行方式

在本机安装 Python 3 后，进入本目录执行：

```bash
python main.py
```

## 预期结果

你会看到一段类似这样的输出：

```text
[项目协调智能体] 已分析任务 TASK-001
[开发智能体] 正在处理
[测试智能体] 测试未通过
[项目协调智能体] 退回开发智能体返工
[开发智能体] 再次处理
[测试智能体] 测试通过
[项目协调智能体] 任务已完成
```
