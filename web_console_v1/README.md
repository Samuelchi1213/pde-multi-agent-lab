# Web 控制台 v1

## 目的

从这一阶段开始，CMD 不再作为主要操作界面。

Web 控制台提供：
- 选择任务
- 启动任务
- 查看当前状态
- 查看 Codex / DeepSeek 调用次数
- 查看 DeepSeek token
- 查看最近日志
- 查看最近任务历史
- 查看人工决策包

## 启动方式

Windows 下直接双击仓库根目录：

`启动多智能体控制台.bat`

浏览器会自动打开：

`http://127.0.0.1:8765`

## DeepSeek Key

页面提供密码输入框。

Key 只作为当前本地 Python 进程启动子任务时的环境变量使用，不写入文件，也不提交 GitHub。

关闭控制台后，需要下次重新输入。

## 当前限制

v1 仍然只能运行预设任务。

下一阶段会增加：
- 自然语言新建任务
- 项目协调智能体自动分级
- 动态选择产品 / 架构 / 开发 / 测试智能体
- 人工决策按钮
- 群聊式时间线


## v2：自然语言入口

新增主入口：

“告诉团队你现在想做什么……”

项目协调智能体会先返回：
- A/B/C/D 任务等级
- 对目标的理解
- 推荐参与的智能体
- 本次范围 / 暂不包含
- 验收标准
- 需要项目负责人补充的问题
- 是否存在必须项目负责人拍板的问题
- 推荐执行通道
- 下一步建议

当前 v2 先做到“自然语言 → 结构化任务草案”。

为了避免模糊需求直接改代码，尚未自动执行自然语言任务。
下一阶段增加“确认任务草案 → 动态组队 → 自动执行”。
